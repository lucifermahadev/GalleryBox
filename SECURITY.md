Security Policy

Supported Versions

Security updates will be provided for the latest version of GalleryBox available in this repository.

Version| Supported
Latest release| ✅
Older releases| ❌

Reporting a Security Vulnerability

If you discover a security vulnerability in GalleryBox, please do not publicly disclose the details before it has been reviewed.

Please report security issues privately through GitHub by contacting the repository maintainer.

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the issue
- The affected version
- The potential impact
- Screenshots or logs, if helpful
- Any suggested fix, if available

Please do not include passwords, API keys, private credentials, personal information, or other sensitive data in your report.

Response

I will review legitimate security reports and, where possible, work toward fixing confirmed vulnerabilities.

Security fixes may be released through a new version of GalleryBox or an appropriate update to the repository.

Responsible Disclosure

Please allow reasonable time for a security issue to be investigated and fixed before publicly disclosing technical details.

Thank you for helping make GalleryBox safer for everyone.
